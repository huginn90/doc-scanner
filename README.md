# 문서 스캐너

휴대폰으로 찍은 사진에서 A4 문서를 찾아, 스캐너로 스캔한 것처럼 반듯하게 펴서 PDF로 만드는 웹앱입니다.
설치 없이 브라우저에서 동작하며, 사진은 서버로 전송되지 않고 기기 안에서만 처리됩니다.

**바로 사용하기:** https://huginn90.github.io/doc-scanner/

## 기능

- **문서 자동 감지:** 사진 속 문서의 네 모서리를 찾습니다. 모서리나 변을 끌어 직접 조정할 수 있고, 끄는 동안 돋보기가 표시됩니다.
- **원근 보정:** 비스듬히 찍은 문서를 A4 비율(또는 원본 비율)의 반듯한 직사각형으로 폅니다.
- **보정 필터 3종**

  | 탭 | 내용 | PDF 저장 형식 |
  |---|---|---|
  | 원본 | 색 그대로 | JPEG |
  | 흑백 | 그림자·조명 보정, 대비 강화, 선명화 | JPEG |
  | **스캔** (기본) | 적응형 이진화로 흑·백만 남김. 연한 글씨와 가는 선도 보존 | 1비트 무손실 |

- **여러 페이지:** 순서 변경, 회전, 다시 편집, 삭제
- **PDF 저장·공유:** 파일로 저장하거나, 지원하는 기기에서는 공유 메뉴로 바로 보낼 수 있습니다.
- **화질 선택:** 표준 150dpi / 고화질 200dpi / 인쇄용 300dpi

## 사용 방법

1. **촬영** 또는 **사진 선택**을 누릅니다. PC에서는 사진을 끌어다 놓아도 됩니다.
2. 자동으로 잡힌 테두리를 확인하고 필요하면 조정한 뒤 **다음**을 누릅니다.
3. 필터·용지·회전을 고르고 **추가**를 누릅니다.
4. 페이지를 모두 추가했으면 **PDF 만들기**를 누릅니다.

사진을 여러 장 한꺼번에 선택하면 자동으로 처리되어 목록에 추가되고, 썸네일을 눌러 개별 편집할 수 있습니다.

> 감지 엔진(OpenCV.js, 약 3.7MB)은 처음 접속할 때 한 번 내려받습니다.
> 감지 결과가 이상하면 주소 끝에 `?debug`를 붙여 감지 방법과 점수를 확인할 수 있습니다.

## 처리 방식

### 문서 감지

감지는 화면이 멈추지 않도록 Web Worker에서 OpenCV.js로 실행합니다.

1. 긴 변 600px로 줄인 사진에 중앙값 필터를 적용해 털·종이 질감 같은 잔무늬를 줄이고, R·G·B 채널별 Canny 경계를 합칩니다. 밝기가 비슷해도 색이 다르면 경계로 잡힙니다.
2. 직선(Hough) 두 쌍의 조합, 윤곽선 근사, 밝은 영역 기반 결과에서 사각형 후보를 만듭니다. 손가락에 가려진 모서리도 두 변의 교차점으로 찾을 수 있습니다.
3. 후보마다 다음을 곱해 점수를 매깁니다.
   - 네 변을 따라 **방향이 맞는** 경계가 있는 비율 (털·글자 질감을 지나는 가짜 변 제외)
   - 면적 (양식 안쪽 표보다 종이 외곽 선호)
   - A4 비율(1:1.414)에 가까운 정도
   - 여백 일관성: 네 변 안쪽 색이 같은 종이 색인지 (책상·키보드까지 끌어안은 사각형 제외)
4. 위→오른쪽→아래→왼쪽 변을 하나씩 다른 직선으로 바꿔 보며 점수가 오르면 교체하고, 각 변을 경계 픽셀에 맞춰 모서리를 정밀하게 보정합니다.
5. 사진을 0·90·180·270°로 돌려 각각 감지하고, 가장 많이 일치한 결과를 씁니다.

### 보정

- **원근 보정:** 쌍삼차(Catmull-Rom) 보간으로 확대해도 글자 가장자리가 덜 뭉개집니다.
- **조명 보정:** 종이 밝기를 추정해 나눠 그림자와 누런 조명을 없앱니다.
- **스캔:** 주변 약 6mm 영역의 평균·표준편차와 비교하는 Sauvola 이진화를 씁니다. 굵은 글씨 속 반사를 채우고, 점 잡티와 페이지 테두리에 붙은 검은 띠를 지웁니다.
- **메모리:** JPEG는 헤더에서 크기·회전 정보를 먼저 읽고 디코딩 단계에서 바로 줄입니다. 원본 최대 크기는 기기 메모리에 맞춰 2200~3200px로 제한합니다.

### PDF

외부 라이브러리 없이 직접 PDF를 씁니다. 원본·흑백 페이지는 JPEG(DCTDecode), 스캔 페이지는 1비트 흑백을 zlib로 압축(FlateDecode)해 넣습니다. 책 표지를 찍은 사진 기준으로 300dpi A4 스캔 페이지 한 쪽이 약 50KB입니다.

## 개발

Node.js 22.12 이상이 필요합니다 (배포 빌드는 Node.js 24 사용).

```bash
npm install
```

```bash
npm run dev
```

개발 서버가 `http://localhost:5173`에서 열립니다. 같은 와이파이의 휴대폰에서도 PC 주소로 접속할 수 있지만, PDF 공유처럼 HTTPS에서만 동작하는 기능이 있어 휴대폰 테스트는 배포된 주소를 쓰는 편이 확실합니다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm test` | 테스트 (Vitest) |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 타입 검사 후 `dist/`에 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |

### 테스트

- `tests/core.test.ts`: 좌표 계산, 원근 보정, PDF 구조
- `tests/cvdetect.test.ts`: 합성 사진으로 문서 감지 (손에 든 책, 흰 책상 위 흰 종이, 표가 있는 양식, 가려진 모서리 등)
- `tests/filters.test.ts`: 흑백·스캔 필터, 1비트 PDF 압축
- `tests/photos.test.ts`, `tests/photos-scan.test.ts`: 실사진 회귀 테스트

실사진 테스트는 `test-photos/` 폴더의 사진을 씁니다. 개인 사진이라 저장소에 올리지 않으며(`.gitignore`), 폴더가 없으면 자동으로 건너뜁니다.

### 구조

```
src/
  main.ts               화면(페이지 목록, 편집기, PDF 내보내기)
  style.css
  worker/
    detect.worker.ts    문서 감지 워커
  lib/
    detector.ts         메인 스레드에서 감지 워커 호출
    cvdetect.ts         OpenCV 기반 문서 감지
    opencv.ts           OpenCV.js 로딩
    imgproc.ts          영역 기반 감지, 원근 보정
    filters.ts          흑백·스캔 필터
    pipeline.ts         감지 → 보정 → 필터 → 회전
    canvas.ts           이미지 디코딩, 캔버스 입출력
    geometry.ts         사각형·호모그래피·출력 크기 계산
    pdf.ts              PDF 작성
tests/                  Vitest 테스트와 합성 이미지 도우미
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다.

## 알려진 한계

- 두꺼운 책은 종이 단면·그림자 때문에 아래쪽 모서리가 수십 px 어긋날 수 있습니다. 평평한 종이 문서에는 해당하지 않습니다.
- 문서 일부가 사진 밖으로 잘리면 감지가 약합니다.
- 새로고침하면 작업 중인 페이지가 사라집니다.
- 4방향 감지와 300dpi 스캔 처리 때문에, 휴대폰에서는 사진 한 장당 몇 초가 걸릴 수 있습니다.

## 사용한 오픈소스

- [OpenCV.js](https://opencv.org/) (`@techstark/opencv-js`, Apache-2.0): 경계·직선·윤곽선 검출
- [Vite](https://vite.dev/), [TypeScript](https://www.typescriptlang.org/), [Vitest](https://vitest.dev/)
- [jpeg-js](https://github.com/eugeneware/jpeg-js): 테스트에서 실사진 디코딩
